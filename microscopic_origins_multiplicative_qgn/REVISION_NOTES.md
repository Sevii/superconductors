# Revision notes: additional-review integration

This package supersedes the first review-integrated draft.

## Substantive additions

1. Added explicit screened-family mismatch tolerances at weighted degrees four and six.
2. Reframed the unscreened molecular-shell family as the generic selector-plus-mixing realization.
3. Added a self-contained statement and proof of the additive one-body Peierls obstruction.
4. Added perturbative-gadget literature and a comparison explaining the exact all-filling and Peierls-covariant features of this construction.
5. Added an explicit Kramers-doubled time-reversal Hamiltonian and a unique closed-shell control implementation.
6. Added a closed-shell Kramers Feshbach verifier showing that the first difference from the single-flavor target scales as \(\lambda^8\).
7. Expanded the weighted local Schrieffer-Wolff regrading, convergence, and support-counting arguments.
8. Added a marked shared active cell to the periodic-control figure.

## Scope retained

The paper still does not claim an onsite-Hubbard-only realization, material parameter extraction, an exact finite-coupling sum of overlapping gadgets, or a dynamical zero-frequency Meissner theorem. The global numerical audit remains one-pair only; all-filling and volume-uniform statements are analytic.

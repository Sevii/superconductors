# O1 implementation specification

## 1. Required inputs

A candidate certificate supplies:

- finite-volume or local-cluster parent row maps `D` or `D_X`;
- positive target metric `G` and certified lower ellipticity `g_minus`;
- full parent zero projector `Z = P_ker(D)` or local zero projectors `p_X`;
- selected branch projector `P <= Z`;
- residual current `J_R`, preferably in a canonical connected-cluster decomposition `J_R = sum_X j_X`;
- parent-row support radius `R_D` and the enlargement convention `X -> X^{+R_D}`;
- translation/momentum symbols when available;
- a proposed local target witness `eta`, local witnesses `eta_X`, or exact Laurent-module data.

## 2. Mandatory safety and frustration-free checks

### Full-zero-space check

Compute or certify

`||Z J_R P|| <= tolerance`.

- If `P=Z`, this is the same as `||P J_R P||`.
- If `P<Z`, checking only `P J_R P` is insufficient.
- A nonzero result is a branch-mixing obstruction, not an `H_s^+` error budget.

### Cluster frustration-free check

For every current cluster, certify

`p_X P = P`.

This is a load-bearing theorem hypothesis. Failure means the local row stack does not annihilate the declared global zero manifold and the cluster factorization theorem cannot be used as stated.

### Cluster-current check

For each canonical current cluster, compute

`u_X = ||p_X j_X p_X||`.

- `u_X=0` certifies local row membership on the local zero sector.
- If nonzero, first sum all symmetry-related terms whose cancellation is mandated by the microscopic expansion, then retest.
- If it remains nonzero, classify the term as unsafe, enlarge the row stack if justified, or add a counterchannel.

## 3. Constructing the witness

### Direct cluster construction

For every safe cluster:

`eta_X = (D_X^+)^† j_X`.

Verify:

- `||D_X^† eta_X p_X - j_X p_X|| <= tolerance`;
- the smallest positive singular value of `D_X`, or a certified upper bound on `||D_X^+||`;
- `support(eta_X) subset X^{+R_D}`;
- the bounded-overlap constant `N_(R_D)` used in the global decay bound.

For an infinite-volume certificate, provide the current decay exponent `mu`, choose `mu'<mu`, and verify the bound

`||eta||_(mu';R_D) <= N_(R_D) exp(2 mu' R_D) C_D M_nu(mu-mu') ||J_R||_mu`.

### Covariant row-metric construction

For

`R_X(A) = D_X(A)^† Y_X(A) D_X(A) / 2`,

use

`eta_X P = Y_X(0) dot(D_X)(0)P / 2`.

Verify the derivative identity directly from displacement-resolved Peierls coefficients.

### Momentum construction: proposed witness

Solve

`D_sharp(z) eta(z) = K(z)`.

A proposed finite range `L` is verified by exact coefficient matching. This is a proof of existence but, by itself, not a proof of nonexistence at larger range.

### Momentum construction: exact module decision

For exact coefficients in an effective field:

1. Set `S = F[z_1,...,z_d]`, `h=z_1...z_d`, and `R=S[h^{-1}]`.
2. Multiply each Laurent column of `D_sharp` and each source column by a power of `h` to clear negative exponents.
3. Let `N` be the polynomial column module generated by the cleared row-map columns.
4. Compute the saturation `N:h^infinity`, for example by eliminating `t` from

   `N S[t] + (1-t h) S[t]^n`.

5. Reduce each cleared source column against a Gröbner basis of the saturated module.

- Zero normal form: membership holds; syzygy/back-substitution data construct a finite Laurent witness.
- Nonzero normal form: no finite-range Laurent witness exists.

In one dimension, Smith normal form is usually simpler. For floating-point material data, exact nonmembership requires rational/algebraic reconstruction or an interval-certified alternative.

## 4. Cost certificates

### Level 0: sparse row norm

If `G >= g_minus I`, certify

`b_cert = g_minus^{-1} sum_alpha a_alpha^2`,

where `a_alpha` bounds the norm of one translated target-row component. A safe mechanical choice is the coefficient `l1` norm of a normalized fermion-monomial expansion.

### Level 1: local-zero compression

Replace `a_alpha^2` by a bound on

`||p_X eta_alpha^† eta_alpha p_X||`.

Use symmetry blocks, exact rational matrices, interval arithmetic, or a model-specific reduced-density formula.

### Level 2: Chebyshev metric inverse

Given `g_minus <= G <= g_plus`, set

`kappa=g_plus/g_minus`, `q=(sqrt(kappa)-1)/(sqrt(kappa)+1)`.

Choose degree `m` and construct a polynomial `p_m` with

`||G^{-1}-p_m(G)|| <= 2 q^(m+1)/g_minus`.

Certify the local density of `eta^† p_m(G) eta`, then add the approximation error times the Level-0 bound for `eta^†eta`.

### Level 3: momentum symbol

For finite-fiber convolution data, evaluate

`F(k)=eta(k)^†G(k)^{-1}eta(k)`.

A grid certificate is

`sup_k lambda_max F(k) <= max_grid lambda_max F + (1/2) sum_i L_i h_i`,

with

`L_i = 2 E E_i/g_minus + E^2 G_i/g_minus^2`.

## 5. Equality diagnostics

The Hodge-projected witness always attains the exact Schur-complement norm, but it need not be the only norm minimizer when `rank(P)>=2`.

For a feasible witness `eta=eta_*+kappa`, define

- `C_* = P eta_*^†G^{-1}eta_*P`;
- `C_kappa = P kappa^†G^{-1}kappa P`;
- `lambda_* = ||C_*||`.

Norm equality holds exactly when

`C_kappa <= lambda_* P - C_*`.

This diagnostic is optional for an upper-bound certificate: any feasible local witness remains valid even when it is not projected.

## 6. Approximate witness path

If exact local factorization fails, set

`cP = Q_D(J_RP-D^†etaP)`.

For a chosen `theta>0`, use

`b <= (1+theta)b_eta + (1+theta^{-1})b_c`,

where

- `b_eta = V^{-1}||P eta^†G^{-1}eta P||`;
- `b_c = (2V)^{-1}||P c^†H_s^+cP||`.

Certify `b_c` by either:

- a positive spectral threshold on the support of `c`;
- a current-weighted low-energy shell estimate;
- a model-specific heat-kernel/random-walk bound.

## 7. Soft-rank-drop diagnostic

If `M(k)` has soft spectral projectors `E_a(k)` with eigenvalues scaling as `r^(2m_a)`, compute `K_a=E_a K_parallel`.

- Bounded Hodge cost requires `||K_a|| = O(r^(m_a))` in every channel.
- Under two-sided spectral scaling and bounded hard channels, this condition is sufficient for bounded symbol cost.
- It does not by itself prove exponential locality. Analytic divisibility or a finite-range module witness is still required.
- Approximate channel projectors require a separate bound on off-block couplings.

## 9. Immediate model audit

Apply the specification to the complete weighted-degree-eight microscopic current:

1. enumerate all connected current clusters after the full Peierls derivative;
2. verify `p_X P = P` and compute `p_X j_X p_X` for every symmetry orbit;
3. construct buffered `eta_X` on safe orbits;
4. test whether unsafe orbit compressions cancel in the complete sum;
5. for exact translation-invariant orbit sums, run the Laurent-module decision;
6. compute `b_cert` and insert it into the existing stiffness floor using the same normalization convention as the parent floor.
